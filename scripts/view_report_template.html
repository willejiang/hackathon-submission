本地 IoU 与官方评分说明

IoU 是轮廓重合度，不是整体三维准确率，也不是官方总分。程序从 CAD 实体生成八个视角的二值轮廓，与参考图计算交集面积 ÷ 并集面积。比较时会裁剪并归一化轮廓，因此它主要反映各视图的形状与比例；绝对尺寸和体积由独立检查负责。

项目本地接受条件是包围盒、体积（容差 2%）、实体数通过，并且六个正交视图的平均 IoU ≥ 0.93。两个等轴视图也报告 IoU，但不进入该门槛。表面积、孔特征、面数等是辅助检查。官方具体评分公式与权重未公开，因此本地指标不能换算成官方总分。

Case 5：高 IoU 仍有明显差异

Case 5 的八视图平均 IoU 是 0.9869，包围盒准确，体积误差约 0.62%；但表面积低约 7.5%，面数和边数不同，通孔拓扑未能测量，孔库存检查也有不匹配。因此它的二维外轮廓接近参考图，但这不能证明内部结构和所有局部特征都正确。当前检查器也不逐项定位孔中心、孔深、壁厚等参数，且对倾斜孔轴的比较有限。

Case 6 是反例：八视图 IoU 0.9155，但体积达到目标的 2.5622 倍，尺寸/体积门槛失败。由此可见，IoU 必须与尺寸、体积和实体检查一起阅读。

每个 case 的模型轮数、cad_build 次数、运行耗时、接口报告 token 和本地评分显示在对应 case 页。Token 可能不包含后台辅助请求；缓存读取包含在报告总量中。
